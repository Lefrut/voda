
# Требования
## Операции изменения корзины
Единообразный вид для каждой операции изменения корзины,
которая в зависимости от `OperationType` предоставляет объект 
типа `CartOperaionStrategy` c вариацией операций:
`sync` (Синхронизация с сервером), `process` 
(Обработка входных данных). `cancel`.

В итоге операция отмены должна быть специфичной для каждого
типа операции. Операция отмены выполняется учитывая 
нынешнее ожидаемое состояние корзины на сервере. 


1. 1 - с 2
2. 2 - с 1
3. 3 - с 5

___

1. 2 - с 
2. 1 - с
3. 3 - с
